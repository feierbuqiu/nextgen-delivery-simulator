# 次世代寄递业务模拟器

这是一个使用虚构机构、虚构人员和合成业务数据的中文前端演练项目。它用于展示通用寄递业务流程、状态约束和本地数据持久化，不代表任何现实机构，也不与任何生产系统连接。

项目架构与源代码为独立实现。公开仓库不包含第三方源代码、图像、字体、数据库、非公开文档、历史研发记录或真实个人信息。通用业务概念仅用于教学和软件工程演练。

## 运行边界

- 仅监听 `127.0.0.1`，不提供互联网部署配置。
- 数据只保存在当前浏览器的本地存储中。
- 所有示例身份、联系方式、地址、机构和业务编号均为虚构或合成内容。
- 不能用于真实收寄、支付、身份核验、授权审批或生产经营。

## 本地运行

建议直接使用 `.node-version` 声明的 Node.js 22.22.2；Node.js 24.15.0 及以上受支持版本也可使用。Node.js 25 不在支持范围内，运行 `npm run dev` 时会收到明确提示，而不会继续进入不可靠的开发模式。

```sh
npm ci
npm run dev
```

浏览器访问 `http://127.0.0.1:4173`。
